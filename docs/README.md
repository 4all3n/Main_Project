# Docs Guide

This folder contains planning documents, workflow explanations, and paper-writing drafts.

Use this file to know what is current vs planning-only.

## Read First

- `../README.md`: project setup and runtime behavior (main source of truth).
- `workflow/backend.md`: backend architecture walkthrough.
- `workflow/frontend.md`: frontend architecture walkthrough.

## Planning Documents (Not Runtime Truth)

These are useful for roadmap context but may include outdated statuses or earlier assumptions:

- `BACKEND_PLAN.md`
- `FRONTEND_PLAN.md`
- `PROJECT_ROADMAP.md`
- `PROGRESS.md`
- `PAPER_PLAN.md`

## Paper Drafts

- `paper/main.tex` and section markdown files are manuscript drafts.
- Draft sections can contain claims that need fresh experimental reruns before publication.

## Recommended Workflow

1. Read `../README.md` for current behavior and setup.
2. Use workflow docs for deeper architecture understanding.
3. Use plan/roadmap files for future tasks, not as implementation status.
